# News Papers 0.5.4

News Papers 0.5.4 fixes the Android shape tool and makes it faster to move around long papers.

- **Shapes on Android.** The shape tool has a new Auto mode, now the default: draw a rough rectangle, circle, triangle, arrow or line and it becomes a clean shape, with a live preview while you draw. Choosing the shape tool opens its shape menu right away, and the tool icon shows the current shape. Before, the menu only opened on a second tap, so every shape came out as a straight line. Existing installs start on Auto once after this update.
- **Page scrollbars.** The original and translation views have a page scrollbar on the right, on the desktop and on Android. Drag it to move through the paper; a bubble shows the page you will land on. On the desktop it also works with the keyboard (arrow keys, Page Up/Down, Home/End), touch and pen. On Android it works while zoomed and never starts an ink stroke.
- **Jump to a page.** On the desktop, click the page number in the reader bar, type a page and press Enter (Esc cancels). On Android, the reader bar shows the current page; tap it to type a page number. Numbers outside the paper go to the first or last page.
